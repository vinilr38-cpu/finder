# finder

LocalServiceFinder - An on-demand local services marketplace connecting customers with verified local professionals (electricians, plumbers, cleaners, technicians) in real time.

## Tech Stack
- **Frontend:** Vite, React, React Router
- **Styling:** Tailwind CSS
- **Maps:** Leaflet & React-Leaflet (OpenStreetMap)
- **Backend / Database:** Firebase Authentication & Cloud Firestore (real-time `onSnapshot` sync)
- **Deployment:** Vercel ready (`vercel.json`)
